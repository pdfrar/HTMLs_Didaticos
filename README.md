## 📁 4º Ano (`4 ano/`)

1. **[representacao_de_imagens.html](file:///c:/Users/pedro/OneDrive/Área%20de%20Trabalho/Pedro/2026/Trabalho/Programações%20Pedagógicas/HTMLs%20Didáticos/4%20ano/representacao_de_imagens.html)**
   - **Tema:** Como o computador guarda uma imagem? Pixels, matriz e código binário (BNCC Computação EF04CO04 e EF04CO05).
