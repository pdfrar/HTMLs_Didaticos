FASE 2 • ENTRADA

O comando input()

+15% XP

O input() faz o programa parar e esperar o usuário digitar alguma coisa. Quando o usuário aperta Enter, o que foi digitado é guardado em uma variável.

Como se escreve:

variavel = input("Pergunta que aparece na tela ")

O texto entre aspas é a pergunta exibida para o usuário. A resposta digitada fica guardada na variável da esquerda. Deixe um espaço no final da pergunta, para que a resposta não fique grudada nela.

Teste o programa: clique em Executar e responda no terminal.

main.py 
nome = input("Qual é o seu nome? ")
print("Olá,", nome)
print("Seja bem-vindo à base CyberPython.")
Simulador de terminal
Console
Clique em Executar para iniciar o programa.

Execute o programa mais de uma vez, com nomes diferentes. O código é o mesmo, mas a saída muda conforme a entrada. É isso que torna um programa interativo.

Ordem de execução: o Python lê o código de cima para baixo. Na linha 1, ele mostra a pergunta e espera. Somente depois que o usuário aperta Enter é que ele segue para a linha 2.
FASE 3 • SAÍDA

Juntando textos: vírgula ou sinal de mais?

+15% XP

Há duas formas de mostrar um texto fixo junto com o conteúdo de uma variável no print():

  • Vírgula ( , ): o Python coloca um espaço automaticamente entre cada parte.
  • Sinal de mais ( + ): o Python cola os textos exatamente como estão, sem acrescentar espaço. Esse processo se chama concatenação.
print("Bem-vindo,", nome)
Com vírgula, o espaço entre as partes aparece sozinho.
print("Bem-vindo," + nome)
Com o sinal de mais, o nome ficou colado na vírgula.
print("Bem-vindo, " + nome + "!")
Com o sinal de mais, o espaço precisa ser escrito dentro das aspas. Assim também é possível colar o ponto de exclamação logo depois do nome.
As duas formas estão corretas. A vírgula é mais prática; o sinal de mais dá mais controle sobre a pontuação e os espaços.

O problema dos números

main.py 
idade = input("Quantos anos você tem? ")

TypeError: o Python não conseguiu fazer a conta

A mensagem can only concatenate str (not "int") to str significa: "só consigo juntar texto com texto, e você tentou juntar um texto com um número inteiro".

Mas o usuário digitou um número! Por que o Python diz que é texto? Execute este segundo programa, que soma dois números digitados:

main.py 
a = input("Primeiro número: ")
b = input("Segundo número: ")
print("Resultado:", a + b)
Sugestão: digite 10 e depois 5
Console
Clique em Executar para iniciar o programa.

A regra do input():

O input() sempre devolve um texto (str), mesmo quando o usuário digita um número. Por isso, "10" + "5" resultou em 105: o Python colou os dois textos, como fez com os nomes na fase anterior.
FASE 5 • CONVERSÃO

A solução: converter com int()

+20% XP

O comando int() transforma um texto que contém um número em um número inteiro de verdade. Para isso, colocamos o input() dentro do int():

Como se escreve:

idade = int(input("Quantos anos você tem? "))

Primeiro o input() recebe o texto digitado; em seguida, o int() converte esse texto em número. Observe que a linha termina com dois parênteses: um fecha o input e o outro fecha o int.
main.py 
idade = int(input("Quantos anos você tem? "))
proximo_ano = idade + 1
print("No ano que vem, você terá", proximo_ano, "anos.")

Console
Clique em Executar para iniciar o programa.

Agora o ciclo EPS está completo: a Entrada é a idade digitada, o Processamento é a conta idade + 1 e a Saída é a frase mostrada pelo print().

Teste: execute de novo e digite uma palavra

Se o usuário digitar doze em vez de 12, o int() não consegue fazer a conversão e o Python mostra um ValueError. O int() só funciona com textos formados por algarismos.
FASE 6 • PROCESSAMENTO

Operações matemáticas

+20% XP

Depois de converter a entrada com int(), o Python pode fazer qualquer uma das quatro operações básicas. Atenção aos símbolos de multiplicação e divisão, que são diferentes dos usados no caderno:

+
Adição
7 + 3 → 10
-
Subtração
7 - 3 → 4
*
Multiplicação
7 * 3 → 21
/
Divisão
6 / 3 → 2.0
