Fase 2 • A Grande Descoberta

O que é uma Variável?

Imagine que a memória do computador é uma sala cheia de baús mágicos. Para não se perder, cada baú tem uma etiqueta com um nome e guarda um valor por vez!

moedas
🪙 100
Tipo: Inteiro (int)

✨ O nome da caixa (moedas) continua o mesmo, mas o que está dentro pode variar!

📦 A Anatomia de uma Variável

Guardar na cabeça estas 3 características vai te transformar num mestre da programação:

🏷️
1. O Nome (Identificador)

É a etiqueta do lado de fora da caixa. É como chamamos a variável no nosso código para pegar o que está lá dentro.

💎
2. O Conteúdo (Valor)

O que está guardado lá dentro agora. Se seu personagem toma dano, o valor da caixa vida diminui!

🧬
3. O Tipo de Dado

Define se é texto, número inteiro, número com ponto ou booleano. O Python descobre o tipo sozinho!

⚡ Por que se chama "Variável"?

Porque o valor guardado pode mudar (variar) quantas vezes forem necessárias ao longo do jogo ou programa!

Fase 3 • Carteira de Motorista Python

As Regras de Ouro dos Nomes

Em Python, você não pode inventar qualquer nome para o seu baú. O computador precisa de ordem para entender perfeitamente o seu código!

🐍
O Estilo snake_case

Em Python, quando o nome tem mais de uma palavra, usamos o traço baixo (_) rastejando no chão, como uma cobrinha:
pontos_do_jogo ✔️

🚫
Proibido Começar c/ Número

O primeiro caractere deve ser letra ou sublinhado.
1lugar ❌ (Erro fatal!)
lugar1 ou primeiro_lugar ✔️

⚠️
Nada de Espaço ou Acentos

Computadores se perdem com espaços e acentos no nome de variáveis:
pontos jogador ❌
pontos_jogador ✔️

Fase 4 • A Chave Mágica

O Sinal '=' não é o que parece!

Na matemática, = significa que os dois lados são idênticos.
Mas em programação, o = significa RECEBE (coloque dentro da caixa)!

A Fórmula Secreta do Python:
nome_da_caixa = valor_guardado

👉 Leia sempre assim: "O baú nome_da_caixa RECEBE o valor valor_guardado".
