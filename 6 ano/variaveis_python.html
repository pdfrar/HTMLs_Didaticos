FASE 2

📦 Caixas de Memória: As Variáveis

+15% XP

Pense rápido: Quando você digita o nome do seu personagem na Entrada, onde o computador guarda esse dado enquanto ele faz o Processamento?

Ele guarda em uma Caixa de Memória! No mundo dos programadores, essa caixa se chama VARIÁVEL.

📌 NOME DA CAIXA: heroi
"Shadow"
Conteúdo guardado na memória RAM

A Anatomia de uma Variável em Python:

Para criar uma variável em Python, você escreve o Nome da Caixa, coloca o símbolo = (que significa "recebe" ou "guarda") e o valor que vai dentro:

variaveis.py 
heroi = "Shadow"       # A caixa 'heroi' guarda o texto "Shadow"
nivel = 1              # A caixa 'nivel' guarda o número 1
ouro = 500             # A caixa 'ouro' guarda 500 moedas

⚠️ CUIDADO COM O SINAL DE IGUAL (=):

Na programação, = não é continha de matemática! Ele se chama Operador de Atribuição. Ele pega o que está na direita e coloca dentro da caixa da esquerda!
FASE 3 • TIPO DADO

📜 Tipo 1: String (str) - O Guardião de Textos

+15% XP

O tipo String (abreviado como str) é usado para armazenar qualquer tipo de texto: nomes, falas de NPCs, senhas e mensagens do sistema.

👑 A REGRA DE OURO DA STRING:

Para o Python saber que algo é um texto, você DEVE USAR ASPAS! Podem ser aspas duplas "assim" ou aspas simples 'assim'. Se esquecer as aspas, o computador vai dar erro achando que você escreveu um comando misterioso!
tipo_string.py 
# ✅ Corretíssimo: Textos sempre protegidos com aspas!
jogador = "Lucas_ProGamer"
arma_secreta = 'Espada Laser Cósmica'
cidade_natal = "Neo Tóquio 2099"

FASE 4 • TIPO DADO

🔢 Tipo 2: Int (Inteiro) - Contadores e Estatísticas

+15% XP

O tipo Int (abreviação de Integer / Inteiro) serve para guardar números redondos, inteiros, sem nenhuma parte quebrada ou com vírgula.

Usamos Int para tudo que podemos contar nos dedos: vidas de um personagem, número de poções, balas no pente ou o ano em que estamos.

🚫 REGRA CRUCIAL DO INT: Números inteiros são escritos SEM ASPAS! Se você colocar "3" entre aspas, o Python vai achar que é uma palavra e você não vai conseguir somar, subtrair ou calcular dano!
tipo_int.py 
# ✅ Números Inteiros: Livres de aspas!
vidas = 3              # Quantidade de vidas restantes
municao = 150          # Cartuchos no inventário
moedas_ouro = 2500     # Pontos acumulados
temperatura = -5       # Sim! Pode ser número negativo também!

FASE 5 • TIPO DADO

💰 Tipo 3: Float (Ponto Flutuante) - Números Quebrados

+15% XP

E quando você precisa de um número com fração ou centavos? Por exemplo: o preço de uma skin por 19.90 ou a altura do robô de 1.85 metros? Para isso usamos o tipo Float!

🚨 ALERTA CRÍTICO: O MAIOR PERIGO DE BUG DO PYTHON! 🚨

No Brasil usamos vírgula para dinheiro (ex: R$ 10,50), MAS O PYTHON FOI FEITO NO PADRÃO INTERNACIONAL!

👉 REGRA OBRIGATÓRIA: NO PYTHON, USE PONTO (.) E NUNCA VÍRGULA (,)!

❌ ERRADO! BUG CRÍTICO!
preco_skin = 19,90
altura_heroi = 1,75

A vírgula confunde o Python completamente! Ele acha que você criou dois números separados em uma lista. O seu jogo vai travar!

✅ CORRETO! PADRÃO PYTHON!
preco_skin = 19.90
altura_heroi = 1.75

Com ponto (.), o Python reconhece perfeitamente como um Float decimal e faz todos os cálculos de dinheiro sem erros!

FASE 6 • TIPO DADO

🔘 Tipo 4: Boolean (bool) - O Interruptor Hacker

+15% XP

O tipo Boolean (ou bool) é o tipo mais simples e poderoso do computador. Ele funciona como um interruptor de luz: só possui 2 valores possíveis no universo inteiro!

True

Significa VERDADEIRO ou Ligado (1)

False

Significa FALSO ou Desligado (0)

🔤 REGRA DE OURO: PRIMEIRA LETRA SEMPRE MAIÚSCULA!

No Python, True e False DEVEM começar com letra maiúscula (True e False). Se escrever com letra minúscula (true ou false), o Python vai reclamar de erro!
💡
VARIÁVEL NO PYTHON:
escudo_ativado = True
