Decisões

Toda decisão começa com uma comparação

OperadorSignificadoExemploResultado
==igual a5 == 5True
!=diferente de5 != 5False
>maior que7 > 10False
<menor que7 < 10True
>=maior ou igual a20 >= 20True

O resultado de uma comparação é sempre True (verdadeiro) ou False (falso). Atenção: = guarda um valor; == compara dois valores.

Testar no OnlineGDB com print(7 < 10) e print(5 == 5) para a turma ver True e False no console. No EV3 Classroom, são os blocos verdes de operadores, com pontas em forma de hexágono. O erro mais comum do dia será escrever = no lugar de ==.

Decisões

if: executar somente se for verdade

Código

distancia = int(input("Sensor (cm): "))
if distancia < 20:
    print("Obstáculo à frente")
    print("Parar motores")
print("Fim da leitura")

Console

Sensor (cm): 12
Obstáculo à frente
Parar motores
Fim da leitura

A linha do if termina com dois-pontos. As linhas com 4 espaços ficam dentro do if e só são executadas quando a condição é verdadeira. A última linha está fora e é executada sempre.

Todos digitam e executam duas vezes: com 12 e com 80. Com 80, só aparece "Fim da leitura". Depois, pedir que tirem os 4 espaços da linha "Parar motores" e executem com 80: a mensagem passa a aparecer sempre, porque saiu do if. É a mesma ideia do encaixe dos blocos vista no encontro 1.

Python

if distancia < 20:
    print("Parar motores")

O else não tem condição: ele vale para todos os casos em que a condição do if é falsa. Ele fica alinhado com o if e também termina com dois-pontos.

Completar o programa do slide anterior com o else e testar com 12 e com 80. Reforçar que, entre if e else, sempre um dos dois blocos é executado, e nunca os dois.

Decisões

elif: mais de dois caminhos

Código

distancia = int(input("Sensor (cm): "))
if distancia < 10:
    print("Recuar")
elif distancia < 30:
    print("Desviar")
else:
    print("Seguir em frente")

Três execuções

Sensor (cm): 5
Recuar

Sensor (cm): 22
Desviar

Sensor (cm): 80
Seguir em frente

O Python testa as condições de cima para baixo e executa apenas o bloco da primeira que for verdadeira. As demais não são verificadas.

elif é a abreviação de "else if" (senão, se). Perguntar: com 5 cm, a condição distancia < 30 também é verdadeira; por que "Desviar" não aparece? Porque o Python para na primeira condição verdadeira. Pedir que troquem a ordem das duas condições e testem com 5, para ver o erro de lógica aparecer.

Decisões

and, or e not: combinar condições

Código

bateria = 75
distancia = 40
botao = "solto"

if bateria > 20 and distancia > 30:
    print("Avançar")

if botao == "apertado" or distancia < 5:
    print("Parada de emergência")

and: verdadeiro quando as duas condições são verdadeiras.

or: verdadeiro quando pelo menos uma é verdadeira.

not: inverte o resultado da condição.

Textos são comparados com aspas: botao == "apertado".

Com os valores do slide, aparece apenas "Avançar". Pedir previsões antes de executar e depois mudar os valores: bateria = 15 (nada aparece) e distancia = 3 (só "Parada de emergência"). Lembrar que a comparação de textos diferencia maiúsculas de minúsculas: "Apertado" é diferente de "apertado".

for i in range(4):

É o bloco “repetir 4 vezes”. A variável i conta as repetições e começa em 0: nas quatro voltas, vale 0, 1, 2 e 3.

É o mesmo exemplo do encaixe mostrado no encontro 1. Pedir que troquem print("Lado", i + 1) por print("Lado", i) para ver a contagem começar em zero. O nome i é um costume; qualquer nome de variável serve.

Repetições

Somar dentro da repetição

Código

total = 0
for i in range(3):
    leitura = int(input("Leitura: "))
    total = total + leitura
print("Média:", total / 3)

Console

Leitura: 20
Leitura: 25
Leitura: 30
Média: 25.0

A variável total começa em 0, antes da repetição, e recebe uma nova leitura a cada volta. Um sensor costuma ser lido várias vezes e usa-se a média das leituras.

Fazer o acompanhamento no quadro: total vale 0, depois 20, 45 e 75. Perguntar o que acontece se a linha total = 0 for colocada dentro do for: o total é zerado a cada volta e a média sai errada (10.0). A divisão com / sempre resulta em número decimal, por isso aparece 25.0.

Repetições

while: repetir enquanto for verdade

Código

bateria = 100
while bateria > 20:
    print("Bateria:", bateria)
    bateria = bateria - 30
print("Recarregar")

Console

Bateria: 100
Bateria: 70
Bateria: 40
Recarregar

Antes de cada volta, o Python testa a condição. Quando ela fica falsa, a repetição termina. Se nada dentro do while mudar a condição, o programa nunca para: use o botão Stop do OnlineGDB.

Acompanhar os valores no quadro: 100, 70, 40 e 10; com 10 a condição é falsa e o programa sai da repetição. Depois, provocar o laço infinito de propósito: comentar a linha bateria = bateria - 30, executar e parar com o Stop. No EV3 Classroom, o equivalente é o bloco "repetir até", com a condição invertida.

Repetições

Qual repetição usar?

for

Quando o número de repetições é conhecido antes de começar.

Andar os 4 lados de um quadrado.

while

Quando a repetição depende de uma condição e não se sabe quantas voltas serão necessárias.

Andar até encontrar um obstáculo.

Pedir outros exemplos do robô para cada caso. Com for: piscar a luz 3 vezes, dar 5 voltas na pista. Com while: seguir a linha enquanto o sensor vê preto, esperar até o botão ser apertado.

O laço do robô

while True e break

Código

while True:
    distancia = int(input("Sensor (cm): "))
    if distancia < 20:
        print("Obstáculo: parar motores")
        break
    print("Seguir em frente")
print("Programa encerrado")

Console

Sensor (cm): 80
Seguir em frente
Sensor (cm): 45
Seguir em frente
Sensor (cm): 12
Obstáculo: parar motores
Programa encerrado

while True é o bloco “repetir para sempre”. O break interrompe a repetição na hora. Programas de robô têm esta forma: ler o sensor, decidir, agir e repetir.

Este é o programa mais importante do encontro: reúne input, conversão, if, repetição e indentação em dois níveis. Digitar junto com a turma, com calma, chamando atenção para os 8 espaços dentro do if. Aqui o input faz o papel do sensor de distância; no curso com ev3dev, essa linha será trocada pela leitura do sensor real e os print, pelos comandos dos motores.
