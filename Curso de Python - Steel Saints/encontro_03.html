O que este programa mostra?

Código

total = 0
while True:
    d = int(input("Sensor (cm): "))
    total = total + 1
    if d < 10:
        break
print("Leituras:", total)

O programa contou as leituras, mas não guardou nenhuma: a variável d só lembra o último valor digitado. Hoje as leituras passam a ficar guardadas em uma lista.

Pedir que a turma leia o código e preveja o console antes de mostrá-lo. Retomar o desafio "Robô em patrulha" do encontro 2 e as dúvidas dos exercícios. Perguntar: depois que o programa termina, é possível saber qual foi a primeira leitura? Não, porque d foi substituída a cada volta. Essa é a motivação das listas.

Listas

Uma variável, vários valores

Sem lista

leitura1 = 20
leitura2 = 25
leitura3 = 30
leitura4 = 18

Com lista

leituras = [20, 25, 30, 18]
print(leituras)
print(len(leituras))

Console

[20, 25, 30, 18]
4

A lista é escrita entre colchetes, com os valores separados por vírgulas. O comando len() informa quantos itens ela tem. Com 100 leituras, a versão sem lista precisaria de 100 variáveis.

No EV3 Classroom existe o bloco de listas (variável do tipo lista), mas a turma provavelmente usou pouco. Destacar que o nome da lista costuma ficar no plural: leituras, cores, comandos. Uma lista vazia é escrita como [].

Código

print(leituras[0])    # 20
print(leituras[2])    # 30
print(leituras[-1])   # 18, o último item

A posição, chamada índice, começa em 0, como no range(). Com 4 itens, os índices vão de 0 a 3.

O símbolo # inicia um comentário: o Python ignora tudo o que vem depois dele na linha. Pedir que a turma teste print(leituras[4]) e leia o erro IndexError: list index out of range. Perguntar como pegar o penúltimo item: leituras[-2].

Listas

Alterar, acrescentar e remover

Código

leituras = [20, 25, 30]
leituras[1] = 27
leituras.append(12)
print(leituras)
leituras.pop()
print(leituras)

Console

[20, 27, 30, 12]
[20, 27, 30]

leituras[1] = 27 troca o valor da posição 1. append() acrescenta um item no fim da lista. pop() remove o último item.

O append() é o comando mais usado hoje: é com ele que as leituras do sensor serão guardadas uma a uma. Chamar atenção para o ponto entre o nome da lista e o comando (leituras.append). Quem quiser pode testar também leituras.remove(30), que remove o item pelo valor.

Listas

for: percorrer os itens da lista

Código

leituras = [32, 18, 45, 9, 27]
for d in leituras:
    if d < 20:
        print(d, "cm: obstáculo")
    else:
        print(d, "cm: livre")

Console

32 cm: livre
18 cm: obstáculo
45 cm: livre
9 cm: obstáculo
27 cm: livre

No lugar do range(), o for recebe a lista. A cada volta, a variável d assume o próximo item, do primeiro ao último.

Comparar com for i in range(5): lá, i recebia 0, 1, 2, 3 e 4; aqui, d recebe os próprios valores da lista. Pedir que acrescentem um contador de obstáculos antes do for (obstaculos = 0) e mostrem o total no fim. Esse é o exercício 2 da prática.

Listas

Guardar as leituras uma a uma

Código

leituras = []
for i in range(4):
    d = int(input("Leitura: "))
    leituras.append(d)
print(leituras)
print("Média:", sum(leituras) / len(leituras))

Console

Leitura: 20
Leitura: 25
Leitura: 30
Leitura: 17
[20, 25, 30, 17]
Média: 23.0

A lista começa vazia, antes da repetição, e recebe um item a cada volta com append(). Ao final, todas as leituras continuam disponíveis para o programa.

É o mesmo programa da média do encontro 2, agora com lista. Perguntar o que acontece se leituras = [] for colocada dentro do for: a lista é esvaziada a cada volta e só a última leitura sobra. É o mesmo erro do total = 0 dentro da repetição.

Listas também guardam textos. Para mudar o percurso, basta alterar a lista.

Pedir que a turma desenhe no caderno o percurso descrito pela lista e depois crie a própria rota, por exemplo um quadrado. Comentar que separar os dados (a rota) das instruções (o for) é uma forma comum de organizar programas de robô.

Módulos

import: trazer comandos prontos

Hoje, no OnlineGDB

import random
import time

Em 2027, no robô com ev3dev

from ev3dev2.motor import LargeMotor
from ev3dev2.sensor.lego import UltrasonicSensor

Um módulo é um conjunto de comandos já escritos, guardado em outro arquivo. O import fica no início do programa e libera esses comandos. O random faz sorteios; o time controla o tempo.

Os motores e sensores do EV3 também chegam ao Python por meio de módulos.

Equivale às extensões do EV3 Classroom, que acrescentam novas categorias de blocos. O Python já vem com centenas de módulos. Não é preciso explicar o from ... import agora: o objetivo é a turma reconhecer a forma quando encontrar código ev3dev na semana 4.

Módulos

random: sortear valores

Código

import random

distancia = random.randint(5, 100)
print("Sensor:", distancia, "cm")

cores = ["verde", "amarelo", "vermelho"]
cor = random.choice(cores)
print("Cor:", cor)

Uma execução

Sensor: 63 cm
Cor: amarelo

random.randint(5, 100) sorteia um inteiro de 5 a 100, incluindo os dois extremos. random.choice() sorteia um item da lista. Cada execução mostra valores diferentes.

Executar três ou quatro vezes para a turma ver os valores mudarem. Destacar a diferença: no randint o último número entra no sorteio; no range ele não entra. Com o random, o programa simula o sensor sem que ninguém precise digitar as leituras.

Módulos

time: fazer o programa esperar

Código

import time

for i in range(3, 0, -1):
    print(i)
    time.sleep(1)
print("Partida!")

Console

3
2
1
Partida!

time.sleep(1) pausa o programa por 1 segundo, como o bloco “esperar 1 segundos”. O valor pode ser decimal: time.sleep(0.5) espera meio segundo.

A diferença só aparece ao executar: os números surgem um por segundo. No robô, a espera é usada entre leituras do sensor e para manter um motor ligado por um tempo. Comentar que o OnlineGDB às vezes mostra a saída de uma vez em conexões lentas.

Juntando tudo

Um sensor simulado

Código

import random
import time

leituras = []
while True:
    d = random.randint(5, 100)
    leituras.append(d)
    print("Sensor:", d, "cm")
    if d < 15:
        print("Obstáculo: parar motores")
        break
    time.sleep(0.5)
print("Leituras:", len(leituras))
print("Menor:", min(leituras))

Uma execução

Sensor: 72 cm
Sensor: 41 cm
Sensor: 88 cm
Sensor: 9 cm
Obstáculo: parar motores
Leituras: 4
Menor: 9

É o laço do robô do encontro 2 com três mudanças: o random no lugar do input, o sleep entre as leituras e a lista que guarda o histórico. Digitar junto com a turma. No ev3dev, a linha do random será trocada pela leitura do sensor ultrassônico real.
