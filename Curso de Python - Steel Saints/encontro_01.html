print() mostra uma mensagem no console. O texto vai entre aspas. Linhas que começam com # são comentários e o Python as ignora.

Todos digitam e executam. Em seguida, pedir que troquem as mensagens e acrescentem uma terceira linha com o próprio nome.

Conceito

Variáveis guardam informações

Uma variável funciona como uma caixa com etiqueta: o nome fica na etiqueta e o valor fica dentro.

O sinal = significa “guardar”. Nomes não têm espaço nem acento: use _ para separar palavras.

Código

nome = "Ana"
idade = 15
velocidade_motor = 50
print(nome)
print(velocidade_motor)

Destacar a variável velocidade_motor: no robô, variáveis guardam velocidades, distâncias e leituras de sensores. Mostrar que print(nome) sem aspas mostra o valor guardado, e print("nome") mostra a palavra nome.

Mão no código

input(): o programa faz perguntas

Código

nome = input("Qual é o seu nome? ")
print("Olá,", nome)

Console

Qual é o seu nome? Ana
Olá, Ana

O input() espera o usuário digitar e apertar Enter. O que foi digitado é guardado como texto, mesmo quando é um número.

No OnlineGDB, o usuário digita a resposta direto no console. Mostrar que a vírgula dentro do print junta as partes com um espaço. Perguntar o que aconteceria se tentássemos somar 5 a uma idade digitada: isso leva ao próximo slide.

int() converte para número inteiro e float() para número decimal. No Python, a casa decimal usa ponto: 3.14.

Mostrar primeiro o erro: sem o int(), idade + 10 gera TypeError, porque o Python não soma texto com número. Depois corrigir com int(). Testar 7 // 2 e 7 % 2 no console para explicar a divisão inteira e o resto.

Cerca de 25 minutos. Circular pela sala e ajudar com os erros mais comuns: aspas, parênteses, conversão com int() ou float() esquecida e Python 3 não selecionado. No exercício 3, o diâmetro pode ser decimal, então pede float().

Desafio do dia

Quantas voltas a roda precisa dar?

O usuário informa a distância que o robô deve percorrer e o diâmetro da roda, em centímetros. O programa mostra quantas voltas o motor precisa dar.

Entrega

Tire um print da tela mostrando o código e o console e envie pelo ClassApp até o fim do encontro.

É o caminho inverso do exercício 3: voltas = distância ÷ (3.14 × diâmetro). A roda padrão do kit EV3 tem cerca de 5,6 cm de diâmetro, então 100 cm dão cerca de 5,7 voltas. Para quem terminar antes: mostrar também quantos graus o motor precisa girar (voltas × 360). Pedir que enviem também os três exercícios.
